# Práctica Git y GitHub
## Propósito
Este repositorio demuestra el uso básico de Git y GitHub usando Codespaces,
con énfasis en commits pequeños y bien explicados.

## Cómo ejecutar / ver
Abrir el archivo `index.html` en el navegador o usar Live Server si está disponible.

## Estructura
- index.html → estructura del mini sitio
- styles.css → estilos básicos
- README.md → documentación del proyecto

## Evaluación formativa
El historial de commits muestra el progreso paso a paso y permite evaluar
cómo se construyó el proyecto, no solo el resultado final.

## Cómo evaluar con commits
Revisar que cada commit tenga un propósito claro y mensajes entendibles.
Los commits pequeños facilitan la retroalimentación.
